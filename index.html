OpenGL সেটআপ / Setup Guide

কোড রান করার আগে OpenGL ও GLUT ইনস্টল করতে হবে

🖥️ Windows (MSYS2 + MinGW)

🇧🇩 বাংলা

ধাপ ১: MSYS2 ইনস্টল করো।

ধাপ ২: টার্মিনালে কমান্ড দাও।

ধাপ ৩: PATH এ C:\msys64\mingw64\bin যোগ করো।

ধাপ ৪: কম্পাইল ও রান করো।

🇬🇧 English

Step 1: Install MSYS2.

Step 2: Run commands in terminal.

Step 3: Add C:\msys64\mingw64\bin to PATH.

Step 4: Compile & run.

📋 Terminal
# Install GCC / GCC ইনস্টল
pacman -S mingw-w64-x86_64-gcc

# Install FreeGLUT / FreeGLUT ইনস্টল
pacman -S mingw-w64-x86_64-freeglut

# Add to PATH / PATH এ যোগ
C:\msys64\mingw64\bin

# Verify / ভেরিফাই
gcc --version
ls /mingw64/lib | grep glut

# Compile & Run / কম্পাইল ও রান
gcc main.c -o app -lfreeglut -lopengl32 -lglu32
./app
💡
প্রতিবার কম্পাইল: gcc main.c -o app -lfreeglut -lopengl32 -lglu32

সবচেয়ে বেসিক OpenGL প্রোগ্রাম — নীল ত্রিভুজ আঁকে। init(), display(), main() বোঝো।

🇬🇧 English

Most basic OpenGL program — draws a blue triangle. Understand init(), display(), main().

📄 hello_opengl.c
#include <GL/gl.h>      // OpenGL মূল লাইব্রেরি
#include <GL/glut.h>    // GLUT উইন্ডো ম্যানেজমেন্ট

// display() - স্ক্রিনে আঁকে / Draws on screen
void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);  // স্ক্রিন ক্লিয়ার
    glColor3f(.25,0.25,1.0);     // রং = নীলচে
    glBegin(GL_POLYGON);           // পলিগন শুরু
        glVertex3f(0.25,0.25,0.0); // বিন্দু ১
        glVertex3f(0.75,0.25,0.0); // বিন্দু ২
        glVertex3f(0.75,0.75,0.0); // বিন্দু ৩
    glEnd();                       // পলিগন শেষ
    glutSwapBuffers();            // বাফার সোয়াপ
}

// init() - সেটিংস / Settings
void init(void)
{
    glClearColor(0,0,0,0);       // কালো ব্যাকগ্রাউন্ড
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(0,1,0,1,-100,1);   // কোঅর্ডিনেট 0-1
}

int main(int argc, char** argv)
{
    glutInit(&argc, argv);
    glutInitDisplayMode(GLUT_DOUBLE | GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("Hello OpenGL");
    init();
    glutDisplayFunc(display);
    glutMainLoop();
    return 0;
}

📏 Topic 01

DDA Line Drawing Algorithm

Digital Differential Analyzer — লাইন আঁকার সবচেয়ে সহজ উপায়

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

DDA দুটি বিন্দুর মধ্যে লাইন আঁকে।

  • dx = |x2-x1|, dy = |y2-y1| বের করো
  • steps = max(dx, dy)
  • x_inc = dx/steps, y_inc = dy/steps
  • লুপে round() করে পিক্সেল বসাও

সমস্যা: float + round() = ধীর।

🇬🇧 English

DDA draws a line between two points.

  • Calculate dx = |x2-x1|, dy = |y2-y1|
  • steps = max(dx, dy)
  • x_inc = dx/steps, y_inc = dy/steps
  • Loop and plot pixels with round()

Drawback: float + round() = slower.

steps = max(|dx|,|dy|) | x_inc = dx/steps | y_inc = dy/steps
Loop: plot(round(x),round(y)); x+=x_inc; y+=y_inc;

💻 Code: DDA Line + Triangle

🇧🇩 বাংলা

DDA দিয়ে লাইন ও ত্রিভুজ। x_inc=(x2-x1)/steps (signed) দিলে যেকোনো দিকে আঁকা যায়।

🇬🇧 English

Line and triangle with DDA. x_inc=(x2-x1)/steps (signed) allows any direction.

📄 dda.c
#include <GL/gl.h>
#include <GL/glut.h>
#include <math.h>  // fabs, fmax, round

// DDA: দুটি বিন্দুর মধ্যে লাইন আঁকে
void DDA(float x1,float y1,float x2,float y2)
{
    float dx=fabs(x2-x1);   // x দূরত্ব
    float dy=fabs(y2-y1);   // y দূরত্ব
    float steps=fmax(dx,dy); // কোনটা বড়?
    float x_inc=(x2-x1)/steps; // signed = যেকোনো দিকে
    float y_inc=(y2-y1)/steps;

    glColor3f(1,1,1);       // সাদা রং
    glBegin(GL_POINTS);
    float x=x1, y=y1;
    for(int i=0;i<=steps;i++)
    {
        glVertex2f(round(x),round(y)); // পিক্সেল বসাও
        x+=x_inc; y+=y_inc;
    }
    glEnd();
}

void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);
    DDA(100,100,200,200);  // লাইন
    DDA(50,50,250,50);    // ত্রিভুজ ভূমি
    DDA(250,50,150,250);  // ডান পাশ
    DDA(150,250,50,50);   // বাম পাশ
    glutSwapBuffers();
}

void init(void)
{
    glClearColor(0,0,0,0);
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(0,300,0,300,-100,1);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DOUBLE|GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("DDA");
    init();
    glutDisplayFunc(display);
    glutMainLoop();
    return 0;
}
⚠️
পার্থক্য: dx/steps = শুধু positive | (x2-x1)/steps = যেকোনো direction (signed)
📐 Topic 02

Bresenham's Line Algorithm

Integer-only, ফাস্ট — DDA এর উন্নত সংস্করণ

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

Bresenham শুধু integer যোগ-বিয়োগ ব্যবহার করে — float না, round() না। তাই ফাস্ট।

Decision Parameter (p):

  • শুরু: p₀ = 2dy - dx
  • p < 0 → (x+1, y), p = p + 2dy
  • p ≥ 0 → (x+1, y+1), p = p + 2dy - 2dx

General: dx>dy → x বরাবর | dy≥dx → y বরাবর। x_change/y_change দিয়ে দিক নির্ধারণ।

🇬🇧 English

Bresenham uses only integer add/subtract — no float, no round(). Faster.

Decision Parameter (p):

  • Initial: p₀ = 2dy - dx
  • p < 0 → (x+1, y), p = p + 2dy
  • p ≥ 0 → (x+1, y+1), p = p + 2dy - 2dx

General: dx>dy → step along x | dy≥dx → step along y.

p₀ = 2dy - dx | p<0: p+=2dy | p≥0: p+=2dy-2dx, y++

💻 Code: Bresenham General

📄 bresenham_general.c
#include <GL/gl.h>
#include <GL/glut.h>
#include <math.h>

// Bresenham General: যেকোনো দিকে লাইন
void Bresenham_General(float x1,float y1,float x2,float y2)
{
    float dx=abs(x2-x1), dy=abs(y2-y1);
    float p;
    float x_change = x1>x2 ? -1:1; // বামে/ডানে
    float y_change = y1>y2 ? -1:1; // উপরে/নিচে

    glBegin(GL_POINTS);
    glVertex2f(x1,y1);

    if(dx>dy) // slope<1: x বরাবর
    {
        p = 2*dy - dx;
        while(1)
        {
            x1 += x_change;
            if(p<0) p += 2*dy;
            else { y1+=y_change; p+=2*dy-2*dx; }
            glVertex2f(x1,y1);
            if(x1==x2) break;
        }
    }
    else // slope≥1: y বরাবর
    {
        p = 2*dx - dy;
        while(1)
        {
            y1 += y_change;
            if(p<0) p += 2*dx;
            else { x1+=x_change; p+=2*dx-2*dy; }
            glVertex2f(x1,y1);
            if(y1==y2) break;
        }
    }
    glEnd();
}

void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);
    glColor3f(1,1,1);
    Bresenham_General(260,240,140,140);
    glutSwapBuffers();
}

void init(void)
{
    glClearColor(0,0,0,0);
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(0,300,0,300,-100,1);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DOUBLE|GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("Bresenham");
    init();
    glutDisplayFunc(display);
    glutMainLoop();
    return 0;
}
✅
DDA vs Bresenham: DDA = float+round() (ধীর) | Bresenham = integer +,- (ফাস্ট) | General = যেকোনো direction
⭕ Topic 03

Midpoint Circle Algorithm

Decision parameter দিয়ে সার্কেল আঁকা — 8-way symmetry

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

Midpoint Circle 8-way symmetry ব্যবহার করে — এক অষ্টাংশ হিসাব করলে বাকি ৭টি অটোমেটিক।

  • শুরু: x=0, y=r, p=1-r
  • p < 0 → p = p + 2x + 3
  • p ≥ 0 → p = p + 2(x-y) + 5, y--
  • প্রতি ধাপে ৮টি প্রতিসম বিন্দু আঁকো
🇬🇧 English

Midpoint Circle uses 8-way symmetry — compute one octant, mirror to get all 8.

  • Start: x=0, y=r, p=1-r
  • p < 0 → p = p + 2x + 3
  • p ≥ 0 → p = p + 2(x-y) + 5, y--
  • Plot 8 symmetric points each step
p₀ = 1-r | p<0: p+=2x+3 | p≥0: p+=2(x-y)+5, y--

💻 Code: Midpoint Circle

📄 midpoint_circle.c
#include <GL/gl.h>
#include <GL/glut.h>

// ৮টি প্রতিসম বিন্দু আঁকে
void plot8(float cx,float cy,float x,float y)
{
    glVertex2f(cx+x,cy+y); glVertex2f(cx-x,cy+y);
    glVertex2f(cx+x,cy-y); glVertex2f(cx-x,cy-y);
    glVertex2f(cx+y,cy+x); glVertex2f(cx-y,cy+x);
    glVertex2f(cx+y,cy-x); glVertex2f(cx-y,cy-x);
}

void MidpointCircle(float cx,float cy,float r)
{
    float x=0, y=r;
    float p=1-r;  // প্রাথমিক decision parameter
    glColor3f(0,1,0); // সবুজ
    glBegin(GL_POINTS);
    plot8(cx,cy,x,y);
    while(x < y)
    {
        x++;
        if(p < 0) p = p + 2*x + 1;
        else { y--; p = p + 2*x - 2*y + 1; }
        plot8(cx,cy,x,y);
    }
    glEnd();
}

void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);
    MidpointCircle(150,150,100);
    glutSwapBuffers();
}

void init(void)
{
    glClearColor(0,0,0,0);
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(0,300,0,300,-100,1);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DOUBLE|GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("Midpoint Circle");
    init();
    glutDisplayFunc(display);
    glutMainLoop();
    return 0;
}
🔄 Topic 04

2D Transformation

Translation, Rotation, Scaling — OpenGL built-in ফাংশন দিয়ে

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

2D Transformation দিয়ে অবজেক্ট মুভ, ঘোরানো, সাইজ বদলানো যায়:

  • Translation: glTranslatef(tx,ty,0) — সরাও
  • Rotation: glRotatef(angle,0,0,1) — z-axis এ ঘোরাও
  • Scaling: glScalef(sx,sy,1) — সাইজ বদলাও

গুরুত্বপূর্ণ: glPushMatrix() ও glPopMatrix() দিয়ে transformation আলাদা রাখো।

🇬🇧 English

2D Transformation moves, rotates, scales objects:

  • Translation: glTranslatef(tx,ty,0)
  • Rotation: glRotatef(angle,0,0,1)
  • Scaling: glScalef(sx,sy,1)

Important: Use glPushMatrix() / glPopMatrix() to isolate transforms.

💻 Code: Keyboard Control + Rotation

🇧🇩 বাংলা

Arrow/WASD দিয়ে নীল বর্গ সরাও। L=ঘোরাও, K=থামাও।

🇬🇧 English

Move blue square with Arrow/WASD. L=rotate, K=stop.

📄 transform_keyboard.c
#include <GL/gl.h>
#include <GL/glut.h>

float px=-8, py=2, speed=0.5, angle=1;

void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);
    // নীল বর্গ (keyboard দিয়ে মুভ)
    glColor3f(.25,.25,1.0);
    glBegin(GL_POLYGON);
        glVertex2f(px,py); glVertex2f(px+4,py);
        glVertex2f(px+4,py-4); glVertex2f(px,py-4);
    glEnd();
    // লাল বর্গ (ঘুরতে থাকে)
    glPushMatrix();            // ম্যাট্রিক্স সেভ
    glRotatef(angle,0,0,1);  // z-axis এ ঘোরাও
    glColor3f(1,0,0);
    glRectf(-2,-2,2,2);
    glPopMatrix();           // ম্যাট্রিক্স রিস্টোর
    glutSwapBuffers();
}

void RotateLeft(){ angle+=10; glutPostRedisplay(); }

// Arrow keys
void specialKeys(int key,int x,int y)
{
    switch(key){
        case GLUT_KEY_RIGHT: px+=speed; break;
        case GLUT_KEY_LEFT:  px-=speed; break;
        case GLUT_KEY_UP:    py+=speed; break;
        case GLUT_KEY_DOWN:  py-=speed; break;
    }
    glutPostRedisplay();
}

// WASD + L/K
void keyboard(unsigned char key,int x,int y)
{
    switch(key){
        case 'w': py+=speed; break;
        case 's': py-=speed; break;
        case 'a': px-=speed; break;
        case 'd': px+=speed; break;
        case 'l': glutIdleFunc(RotateLeft); break; // ঘোরাও
        case 'k': glutIdleFunc(NULL); break;       // থামাও
    }
    glutPostRedisplay();
}

void init(void)
{
    glClearColor(0,0,0,0);
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(-10,10,-10,10,-100,1);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DOUBLE|GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("2D Transform");
    init();
    glutDisplayFunc(display);
    glutKeyboardFunc(keyboard);
    glutSpecialFunc(specialKeys);
    glutMainLoop();
    return 0;
}
🎬 Topic 05

Animation

Timer function দিয়ে অটো অ্যানিমেশন — বাউন্সিং অবজেক্ট

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

Animation এর মূল কৌশল:

  • glutTimerFunc(ms, func, val) — প্রতি ms এ func কল
  • func এ position আপডেট করো
  • glutPostRedisplay() দিয়ে রিড্র
  • আবার glutTimerFunc কল (recursive)
  • বাউন্স: সীমানায় speed = -speed
🇬🇧 English

Animation key technique:

  • glutTimerFunc(ms, func, val) — calls func every ms
  • Update position inside func
  • glutPostRedisplay() to redraw
  • Call glutTimerFunc again (recursive)
  • Bounce: at boundary, speed = -speed

💻 Code: Bouncing Animation

📄 animation_bounce.c
#include <GL/gl.h>
#include <GL/glut.h>

float p = -8;       // x পজিশন
float speed = 0.1;  // গতি

void display(void)
{
    glClear(GL_COLOR_BUFFER_BIT);
    glColor3f(.25,.25,1.0);
    glBegin(GL_POLYGON);
        glVertex2f(p,2); glVertex2f(p+4,2);
        glVertex2f(p+4,-2); glVertex2f(p,-2);
    glEnd();
    glutSwapBuffers();
}

void update()
{
    p = p + speed;              // এগোও
    if(p >= 6 || p <= -10)    // সীমানা?
        speed = -speed;         // বাউন্স!
    glutPostRedisplay();
}

void myTimer(int val)
{
    update();
    glutTimerFunc(100, myTimer, 0); // আবার কল!
}

void init(void)
{
    glClearColor(0,0,0,0);
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    glOrtho(-10,10,-10,10,-100,1);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DOUBLE|GLUT_RGB);
    glutInitWindowSize(500,500);
    glutCreateWindow("Animation");
    init();
    glutDisplayFunc(display);
    glutTimerFunc(100, myTimer, 0); // টাইমার শুরু!
    glutMainLoop();
    return 0;
}

Shapes & 3D VR Room

বিভিন্ন শেপ এবং 3D পার্সপেক্টিভ ভিউ

📖 Theory / তত্ত্ব

🇧🇩 বাংলা

3D ভিউ এর জন্য:

  • gluPerspective(fov,ratio,near,far) — 3D পার্সপেক্টিভ
  • gluLookAt(ex,ey,ez,cx,cy,cz,ux,uy,uz) — ক্যামেরা
  • glEnable(GL_DEPTH_TEST) — depth buffer
  • glutSolidCube(1) — 3D কিউব

WASD দিয়ে ক্যামেরা মুভ, A/D দিয়ে তাকানোর দিক।

🇬🇧 English

3D View requires:

  • gluPerspective(fov,ratio,near,far)
  • gluLookAt(ex,ey,ez,cx,cy,cz,ux,uy,uz)
  • glEnable(GL_DEPTH_TEST)
  • glutSolidCube(1)

WASD moves camera, A/D changes look direction.

💻 Code: 3D VR Room

📄 vr_room.c
#include <GL/glut.h>
#include <math.h>

float angle=0, lx=0, lz=-1; // ক্যামেরা দিক
float x=0, z=5;              // ক্যামেরা পজিশন

void drawRoom()
{
    glColor3f(0.6,0.6,0.6);  // মেঝে
    glBegin(GL_QUADS);
        glVertex3f(-10,0,-10); glVertex3f(-10,0,10);
        glVertex3f(10,0,10);   glVertex3f(10,0,-10);
    glEnd();
    glColor3f(0.8,0.7,0.5);  // দেয়াল
    glBegin(GL_QUADS);
        glVertex3f(-10,0,-10); glVertex3f(-10,8,-10);
        glVertex3f(10,8,-10);  glVertex3f(10,0,-10);
    glEnd();
}

void drawTable()
{
    glPushMatrix();
    glTranslatef(0,1,-3);
    glColor3f(0.5,0.2,0.1);
    glPushMatrix();
    glScalef(2,0.2,1);
    glutSolidCube(1);
    glPopMatrix();
    float leg[4][2]={{.8,.4},{-.8,.4},{.8,-.4},{-.8,-.4}};
    for(int i=0;i<4;i++)
    {
        glPushMatrix();
        glTranslatef(leg[i][0],-0.6,leg[i][1]);
        glScalef(0.1,1.2,0.1);
        glutSolidCube(1);
        glPopMatrix();
    }
    glPopMatrix();
}

void display()
{
    glClear(GL_COLOR_BUFFER_BIT|GL_DEPTH_BUFFER_BIT);
    glLoadIdentity();
    gluLookAt(x,2,z, x+lx,2,z+lz, 0,1,0);
    drawRoom(); drawTable();
    glutSwapBuffers();
}

void reshape(int w,int h)
{
    if(h==0) h=1;
    glMatrixMode(GL_PROJECTION);
    glLoadIdentity();
    gluPerspective(45,(float)w/h,0.1,100);
    glMatrixMode(GL_MODELVIEW);
}

void keyboard(unsigned char key,int xx,int yy)
{
    float f=0.3;
    switch(key){
        case 'w': x+=lx*f; z+=lz*f; break;
        case 's': x-=lx*f; z-=lz*f; break;
        case 'a': angle-=.05; lx=sin(angle); lz=-cos(angle); break;
        case 'd': angle+=.05; lx=sin(angle); lz=-cos(angle); break;
        case 27: exit(0);
    }
    glutPostRedisplay();
}

void init()
{
    glEnable(GL_DEPTH_TEST);
    glClearColor(0.5,0.8,1.0,1.0);
}

int main(int argc,char** argv)
{
    glutInit(&argc,argv);
    glutInitDisplayMode(GLUT_DEPTH|GLUT_DOUBLE|GLUT_RGBA);
    glutInitWindowSize(800,600);
    glutCreateWindow("VR Room");
    init();
    glutDisplayFunc(display);
    glutReshapeFunc(reshape);
    glutKeyboardFunc(keyboard);
    glutMainLoop();
    return 0;
}
💡
3D Controls: W=সামনে, S=পেছনে, A=বামে তাকাও, D=ডানে তাকাও, ESC=বন্ধ
